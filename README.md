# Block Buster

A brick breaker game in C++ with SFML 3.
CS1002 Programming Fundamentals, Fall 2026

## Author

## Controls
- Left / Right or A / D: move the paddle
- Space: launch the ball
- Esc: save the game and return to the menu
- Up / Down / Enter: choose in the menu

## How to run
1. Install SFML 3.1.0 and set it up in Visual Studio (x64).
2. Open BlockBuster.sln.
3. Press Ctrl+F5.
